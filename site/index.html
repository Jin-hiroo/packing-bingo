持ちものビンゴ

修学旅行の持ち物チェックリストを、ビンゴ（ふつうは4×4。3×3や5×5、真ん中のFREEマスも）にするReactコンポーネントです。持ち物をかばんに入れるたびにタップしてスタンプ。列がそろうと、コンボと花火で盛り上がります。

試してみる

修学旅行の持ち物です。マスをタップするとスタンプが押せます。2.5秒以内に続けるとコンボ、タテ・ヨコ・ナナメがそろうとビンゴです。進み具合はこのブラウザに保存されます。

演出だけ見る

途中まで埋まった状態から始まります。下のボタンで、ビンゴやパーフェクトの演出を自動で再生できます。こちらは保存しません。

マスの数を変える

size で2×2から10×10までの n×n のカードにできます。奇数のときは free で、真ん中をはじめからスタンプ済みのFREEマスにできます。下で選ぶと、その大きさのカードに変わります。こちらは保存しません。

5×5
2345678910

サイトに組み込む

コピーして貼り付けるだけで、上の「試してみる」と同じカードがサイトの好きな場所に置けます。保存の設定は要りません。くわしくは README を見てください。

1インストールする

{{install}}

2表示したい場所に置く

{{usage}}

Next.js（App Router）で専用のページにするなら、app/packing/page.tsx に：

{{nextPage}}

3持ち物を変える

items に、左上から横に1行ずつ並べて渡します。下のリストを書き換えて使ってください。

{{items}}

Reactを使っていないページなら

インストールなしで、HTMLの好きな場所に貼るだけで動きます。

{{html}}

デモコード

そのまま動かせるサンプルのプロジェクトです。フォルダごとコピーして、自分のサイトの土台にもできます。

  • Next.js

    App Routerのページに置く例と、ビンゴの瞬間を受け取る例。

    cd examples/nextjs && npm install && npm run dev

  • Vite + React

    ふつうのReactアプリのページに置く例。

    cd examples/vite-react && npm install && npm run dev

  • HTMLだけ

    Reactもインストールも使わない例。ファイルをブラウザで開くだけで動きます。

    examples/html/index.html

1ファイルにまとめた単体のページもあります。
